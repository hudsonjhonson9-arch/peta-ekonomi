Stack Arsitektur: peta-ekonomi

Frontend: SPA Modern (Single Page App)

React 18 + Vite 5 + Tailwind CSS. Navigasi instan tanpa reload halaman, Recharts untuk visualisasi dinamis, custom components modal & select searchable.

Backend: Express 5 Node.js

REST API modular (`satudata-routes.js`, `portal-routes.js`, `screening.js`). Aturan otorisasi sentral melalui `kebijakan.js` dan pembatas laju `rate-limit.js`.

Database: PostgreSQL via `pg`

Relational Database murni dengan connection pool langsung. Query real-time menjamin perubahan di bank data dan RKA seketika muncul di dashboard.

Storage: Google Drive via Google Apps Script

Bebas beban penyimpanan lokal. File PDF, gambar, dan dokumen perencanaan disimpan di Drive dengan validasi header magic bytes di server.

Stack Arsitektur: satudata-kabkota

Frontend: SSR Blade + Alpine.js + Preline UI

Server-Side Rendered (Blade) dengan Tailwind CSS 4, Alpine.js untuk interaktivitas komponen, FilePond untuk drag-and-drop unggahan data.

Backend: Laravel 13 (PHP 8.4) + Octane

Framework PHP enterprise dengan FrankenPHP/Octane server, integrasi Spatie Permission (RBAC) & Spatie ActivityLog untuk audit trail ketat.

Database & Cache: MySQL 8 + Redis

Struktur relasi lengkap 25 migrasi Eloquent. Redis dimanfaatkan untuk antrean background worker, session pengguna, dan rate-limiting.

DevOps: Docker, Caddy, & Backup Scripts

Dilengkapi file `compose.yml`, `Caddyfile` TLS reverse proxy, dan bash script teruji untuk instalasi dari file ZIP di Windows (Laragon/XAMPP) maupun Linux.

Perbandingan Aspek Keamanan & Skalabilitas

OTENTIKASI & RBAC
peta-ekonomi

Login berbasis NIP & Password (bcrypt hash). Session cookie 30 hari. Middleware sentral `kebijakan.js` memetakan path endpoint ke hak (PUBLIK, LOGIN, BANKDATA, REVIEW, ADMIN).

satudata-kabkota

Login username/email + Password (bcrypt) + 2FA TOTP (Google Authenticator) via Fortify. Matriks izin Spatie Permission di database dengan scope akses OPD yang sangat ketat.

PROTEKSI SERANGAN SIBER
peta-ekonomi

Rate Limiter IP (`rate-limit.js`) untuk proteksi brute-force & DoS. Validasi magic bytes biner pada file upload untuk mencegah file malware berkedok PDF.

satudata-kabkota

Proteksi CSRF bawaan Laravel, Sanitasi HTML (Symfony HtmlSanitizer), captcha custom pada formulir QnA dan publik, rate limiting berbasis Redis.

AUDIT TRAIL & LOGGING
peta-ekonomi

Tabel `audit_logs` dan `kertas_kerja_periode_history` mencatat aksi pengguna, dokumen yang diunggah, perubahan status telaah RKA, dan tautan periode.

satudata-kabkota

Spatie Activity Log mencatat seluruh perubahan model database secara detail (nilai lama vs nilai baru), logging Sentry terintegrasi untuk menangkap crash.

Panduan Pengambilan Keputusan untuk BAPPERIDA Sumba Barat

Berdasarkan analisis kode, `peta-ekonomi` bukan pesaing yang saling menggantikan dengan `satudata-kabkota`, melainkan versi adaptasi khusus yang diperkaya untuk alur kerja BAPPERIDA. Berikut 3 skenario yang dapat dipilih:

REKOMENDASI TERBAIK

Skenario A: Sinergi Dua Sistem

Gunakan kedua sistem sesuai ranahnya masing-masing:

  • • Dapur Kerja: Jalankan peta-ekonomi di internal BAPPERIDA untuk telaah RKA (SSH/SBU), kertas kerja, arsip, dan pengumpulan indikator ekonomi.
  • • Etalase Resmi Pemda: Jalankan satudata-kabkota di bawah koordinasi Walidata (Diskominfo) untuk portal Satu Data resmi yang terkoneksi ke SDPDN Nasional.
  • • Sinkronkan dataset yang telah disahkan dari peta-ekonomi ke satudata-kabkota melalui API.
HEMAT SUMBER DAYA

Skenario B: Mandiri di peta-ekonomi

Jika Pemda Sumba Barat belum siap memelihara server Laravel/MySQL/Redis terpisah:

  • • Cukup jalankan peta-ekonomi saja.
  • • Portal Publik dan Bank Data di peta-ekonomi sudah lengkap dan siap diakses masyarakat.
  • • Hemat biaya server (Node + PostgreSQL + Google Drive gratis).
KEPATUHAN REGULASI SDI

Skenario C: Migrasi Penuh ke Satudata

Bila ada mandat resmi provinsi/nasional bahwa portal kabupaten wajib memakai rilis SASANDO/SKALA:

  • • Pasang satudata-kabkota-v2026.10.27 di server Pemda.
  • • Fokuskan hanya untuk portal data terbuka dan indikator daerah.
  • • Catatan: Modul Screening RKA dan Kertas Kerja tetap harus dipertahankan di peta-ekonomi karena tidak didukung di Laravel Satudata.
